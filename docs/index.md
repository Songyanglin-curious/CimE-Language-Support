# Docs

## GB/T 30149—2013

- `test-data/GBT30149-2013-horizontal.CIME`：依据报批稿第 5.6 节及图 4 的 `@` 横表式数据块整理，保留对象指针示例。
- `test-data/GBT30149-2013-vertical.CIME`：依据报批稿第 5.6 节图 2/图 3 的 `@#` 纵表式语法整理；规范图示使用占位字段和值，因此样例也保留占位符。
- 2013 对象数据块允许以 `<类名::实体名>` 开始，但结束标签只写 `</类名>`；扩展中的折叠提供器按类名配对，并将每个 `@`/`@#` 表头归属到包含它的最内层标签，不对 `<E>` 或其他标签名做特判。
